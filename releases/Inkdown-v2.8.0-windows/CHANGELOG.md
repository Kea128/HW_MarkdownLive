## [2.8.0] - 2026-11-10

### Mermaid 图表

- 新增 Mermaid 11.15.0：`mermaid` 代码块在排版视图中直接显示为图表，支持流程图、时序图、类图、甘特图、思维导图等 20 余种图表。
- 图表跟随明暗主题即时切换；语法错误在原位置显示错误信息，不影响其他内容。
- 悬停图表后点击“编辑”可在代码下方实时预览；代码块语言列表新增 mermaid 并提供语法高亮。
- 源码模式工具栏新增“Mermaid 图表”按钮，插入可直接修改的流程图模板。
- Mermaid 按需加载，并以 strict 安全级别净化标签、禁用脚本和点击回调。

### 修复与改进

- 修复 KaTeX 的一个小字体被打包为 data URI 后遭内容安全策略拦截，部分大号括号显示异常的问题。
- 修复悬停段落或代码块时，块操作手柄被挤到编辑区右侧外并出现横向滚动条的问题。
- 代码块的复制、编辑、隐藏、预览等按钮改为中文。

### 发布与验证

- 端到端测试和打包版冒烟测试新增 Mermaid 渲染、主题切换与内容安全策略检查。

## [2.7.1] - 2026-11-04

### 在线更新

- 修复代理服务器要求身份验证时，“检查更新”一直停留在检查中、无法再次检查的问题，现在会明确提示原因。
- 检查超过 60 秒仍未完成时自动结束并提示超时，可以立即重新检查。
- 下载更新期间可通过“帮助 > 取消下载更新”中止；发现新版本时显示安装包大小。
- 软件内的更新说明改为整洁的纯文本，过长时按整行截断。
- 更新模块改为首次检查时才加载，启动时不再额外载入约 0.1 秒的模块。
- 读屏软件不再每秒播报下载进度。

### 发布与验证

- 更新说明由 CHANGELOG 生成并写入 `latest.yml`，2.7.0 也能显示整洁的更新内容。
- 打包版冒烟测试确认更新模块不在启动时加载，并能从安装包内正常载入。

## [2.7.0] - 2026-10-08

### 在线更新

- 新增“帮助 > 检查更新”，从 GitHub Releases 获取最新正式版本并显示版本号与更新内容；仅在手动检查时联网。
- 安装版可在软件内下载新版本，校验 SHA-512 后重启完成升级，也可以选择在退出 Inkdown 时自动安装。
- 重启安装前会先确认未保存的更改；取消后保留已下载的更新，下载进度同步显示在状态栏和任务栏。
- 便携版与 ZIP 版检查到新版本时打开对应发布页面；网络、代理、校验失败或缺少发布时给出明确提示。
- 新增“访问发布页面”和“关于 Inkdown”菜单项。

> 2.6.0 及更早版本不包含更新程序，需要手动安装一次 2.7.0；之后的版本均可在软件内在线升级。

### 发布与验证

- 打包时生成在线更新描述文件 `latest.yml` 与差分 blockmap，整理发布目录时校验其版本和安装包文件名。
- 新增 `npm run publish:github`：校验 SHA-256、`latest.yml` 的 SHA-512 与远端标签后创建 GitHub Release 并上传全部产物。
- 打包版冒烟测试增加更新源配置和“检查更新”菜单校验；新增在线更新策略、流程、状态栏与 Electron 菜单测试。
- 修复 Node.js 25 及以上版本内置的 `localStorage` 遮蔽 jsdom 实现，导致组件测试失败的问题。

## [2.6.0] - 2026-08-19

### 编辑可靠性

- 文档变更改为可等待的合并同步队列；保存、新建、打开、关闭前保证主进程已收到最后一次编辑。
- 原生文件菜单统一复用渲染层操作入口，修复刚输入后立即使用菜单保存可能写入旧内容的竞态。
- 加固主进程回显与本地待同步内容的合并规则，避免较旧 snapshot 覆盖正在输入的正文。

### 架构与性能

- 拆分源码编辑操作和公式 DOM 装饰模块，公式块未就绪时不再阻断后续编号与导航。
- 公式源码匹配容忍换行和尾随空白差异，并过滤与公式无关的 DOM 变化以减少长文档开销。
- Milkdown 改为真正按需加载；源码行号由逐行 DOM 节点改为轻量文本层，并修复重复标题导航。
- 统一顶栏和原生菜单的主题状态，清理旧预览组件、无消费 IPC、死 CSS 及 51 个无用依赖包。

### 验证与发布

- 新增 WYSIWYG 生命周期、公式装饰、数学分隔符和即时保存回归测试，覆盖率提升至 85% 以上。
- 发布流程加入 lint、类型、单元、覆盖率、Electron E2E 和打包版冒烟门禁。
- 发布后自动清除旧版本目录与 electron-builder 中间产物，只保留最新校验产物。

## [2.0.0] - 2026-08-07

### 桌面重构

- 从 PWA 完整迁移到 Electron + React + TypeScript + Vite Windows 桌面架构。
- 增加原生菜单、系统文件对话框、直接覆盖保存、另存为、最近文件、拖放打开和文件关联。
- 增加文件路径/脏状态/窗口标题、未保存确认、崩溃草稿恢复及外部文件变化提示。
- 增加窗口边界持久化、系统主题、UTF-8 BOM/中文路径和编辑/预览滚动同步。

### 安全

- 启用 context isolation 和 sandbox，禁用 renderer Node 集成。
- 文件系统只通过白名单 IPC 与严格参数验证访问；渲染进程不能执行 shell。
- 阻止页面导航和新窗口；仅允许 http、https、mailto 外链交给系统浏览器。
- 添加 CSP，并继续使用 Markdown 节点白名单净化和语法高亮。

### 发布

- Windows x64 NSIS 安装包、便携 EXE、ZIP 和 SHA-256 发布流程。
- 删除 Service Worker、Web Manifest、浏览器下载和 HTTP 部署发布物。
- 当前构建未代码签名。

## [1.0.0] - 2026-08-07

### 新增

- 本地优先 Markdown 编辑、GFM 预览、语法高亮、主题、统计与四种视图。
- Markdown 文件导入/下载、净化后的独立 HTML 导出和浏览器自动保存。
- 可安装、离线可用的 PWA，以及 Microsoft Edge 端到端测试。
- `npm run release` 静态发布目录、ZIP、部署说明、版本说明与 SHA-256 生成流程。

### 修复

- 防止并发文件读取中较慢的旧文件覆盖较新的文稿，并阻止卸载后的异步更新。
- 延迟释放下载 Blob URL，并在组件卸载时统一清理 URL 与计时器。
- 本地存储被禁用或达到配额时不再影响主题和编辑，自动保存失败会明确提示。
- 修复 Windows 保留文件名、尾随点/空格和 HTML 标题转义边界。
- 站内锚点不再错误地打开新窗口，外部 HTTP(S) 链接仍启用隔离保护。
- PWA 改用相对资源、启动地址与作用域，支持部署到静态站点子目录。

### 重构

- 将文件读取、下载、HTML 导出及相关资源生命周期从主界面拆分到独立 Hook。

> Inkdown 是独立实现，未使用、复制或逆向 Typora 私有源码。
