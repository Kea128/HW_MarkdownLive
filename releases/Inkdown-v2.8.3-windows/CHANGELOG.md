# 更新日志

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## 未发布

## [2.8.3] - 2026-11-12

### 图片粘贴

- 修复 Ctrl+V 粘贴截图或复制的图片无法使用的问题：图片保存到与文档同名的 `.assets` 文件夹（如 `周报.md` 的图片存入 `周报.assets/image-20261112170405123.png`），并插入相对路径，源码模式同样适用。
- 粘贴或拖入文档文件夹以外的图片文件时复制一份到图片文件夹，移动或分享文档时图片不会丢失；文档文件夹内的图片直接引用。
- 未保存的新文档中粘贴的图片先暂存，首次保存时自动移入图片文件夹并改写链接；另存到其他文件夹时，原有的相对路径图片会一并复制。
- 新增“文件 > 图片保存位置”，可改为与文档同名的文件夹，或文档所在目录的 assets 文件夹。
- 从 Word、Excel 或网页复制的图文内容仍按文字粘贴；状态栏会提示图片保存到了哪里。

## [2.8.2] - 2026-11-11

### 图片

- 修复打开 Typora 文档时图片无法显示的问题：支持相对文档的路径（如 `笔记.assets/image.png`）、Typora 默认的绝对路径、`file://` 链接以及含空格或 `%20` 的路径。
- Typora 缩放后以 `<img style="zoom:50%">` 保存的图片按比例显示，并保留 `<center>`、`align` 居中；其他 HTML 仍按原文显示。
- 修复编辑文档后，独占一行的图片说明文字被改写为“1.00”的问题，图片的 Markdown 写法保持原样。
- 拖入图片文件时插入图片的本地路径（图片在文档所在文件夹内时使用相对路径），不再误当作文档打开。

### 意见反馈

- 汇总脚本也统计尚未打标签的 `[反馈]` issue；新增 `--label-missing`，在 GitHub Actions 不可用时于本地补打标签。
- 新增“图片”“兼容性”自动标签。

### 安全

- 本地图片通过 `inkdown-image:` 协议加载，只读取图片扩展名的文件，页面脚本无法读取图片内容。

## [2.8.1] - 2026-11-10

### 新功能

- 新增“打开文件夹”（Ctrl+Shift+O）：侧栏“文件”页列出文件夹及子文件夹中的 Markdown 文件，点击即可打开；下次启动自动恢复，切回窗口时自动刷新。

### 修复与改进

- 修复打开含表格等内容的文档后，未做修改也显示“有未保存的更改”、切换文件时反复弹出保存确认的问题。
- 侧栏可拖动右边缘调整宽度，也可用方向键调整、双击恢复默认，宽度会被记住。
- 紧凑、标准、宽松三档排版的段落、标题、列表和表格间距随行高一起变化，差别更明显。
- 修复表格中较长的行内代码溢出单元格、覆盖相邻文字的问题，现在会在单元格内换行。
- 源码模式的编辑区随窗口宽度铺满，不再固定为居中窄栏。

### Mermaid 12 说明

- 深色主题下，使用 redux-color 配色的图表自动换用对应的 redux-dark-color 配色。
- 如需旧版布局与样式，可在图表开头的 front matter 中设置 `layout: dagre` 和 `look: classic`。
- 旧文档中带 `-beta` 后缀的图表写法继续有效；Mermaid 与应用共用同一份 KaTeX，安装包内不再重复打包。

### 意见反馈的收集与整理

- 反馈只包含填写的内容，不附带正在编辑的文档；版本与系统信息需勾选才附带，联系方式不会公开到 GitHub。
- 每条反馈都会在本机 `feedback/feedback.jsonl` 中保留一份记录，无法访问 GitHub 时也能导出汇总。
- GitHub 上的反馈由工作流按类型、功能和关键词自动打上 `type:`、`area:`、`tag:` 标签。
- `npm run feedback:report` 汇总 GitHub 与本机记录，按功能和标签聚合共性问题，标出疑似重复反馈并按优先级排序。

### 验证

- 在桌面端逐一验证 32 种 Mermaid 图表在浅色和深色主题下渲染正常，且不违反内容安全策略。
- 端到端测试新增打开文件夹、拖动侧栏、三档间距、表格长代码换行、源码铺满与提交反馈的检查；打包版冒烟测试新增文件夹与菜单检查。

## [2.6.0] - 2026-08-19

### 编辑可靠性

- 文档变更改为可等待的合并同步队列；保存、新建、打开、关闭前保证主进程已收到最后一次编辑。

- 拆分源码编辑操作和公式 DOM 装饰模块，公式块未就绪时不再阻断后续编号与导航。

- Milkdown 改为真正按需加载；源码行号由逐行 DOM 节点改为轻量文本层，并修复重复标题导航。
- 统一顶栏和原生菜单的主题状态，清理旧预览组件、无消费 IPC、死 CSS 及 51 个无用依赖包。

### 验证与发布

- 新增 WYSIWYG 生命周期、公式装饰、数学分隔符和即时保存回归测试，覆盖率提升至 85% 以上。
- 发布流程加入 lint、类型、单元、覆盖率、Electron E2E 和打包版冒烟门禁。
- 发布后自动清除旧版本目录与 electron-builder 中间产物，只保留最新校验产物。
